# 👻 Pokémon Gengar Landing Page

A visually striking Pokémon-inspired landing page featuring **Gengar** from Generation I.  
Built using pure HTML and CSS, this project focuses on modern UI styling, layered positioning, typography, and aesthetic composition inspired by gaming showcase pages.

![Preview](./Gengar-removebg-preview.png)

---

## ✨ Features

- 👾 Pokémon-themed UI design
- 🎨 Purple aesthetic inspired by Gengar
- 🖼️ Layered image composition
- 📱 Clean modern landing page layout
- ⚡ Custom typography
- 🎯 Floating Pokéball background effect
- 🍔 Minimal top navigation icon
- 🔘 Vertical slider indicator dots

---
